# Mosaic Learning Signals

## Zweck

Dieser Ordner sammelt Lern- und Bewertungssignale fuer Mosaic Workbench.

Im MVP bedeutet das nicht externes Modelltraining, Fine-Tuning oder einen sichtbaren Trainingsmodus.

Lernsignale bedeuten:

- Golden Examples
- Negative Examples
- Preference Cases
- Skill Candidates
- Evaluation Cases
- Swarm Discovery Results

## Dateien

- `hermes-swarm-training-cases.json` - erste Lern- und Bewertungsfaelle aus dem Swarm Deep Run. Dateiname bleibt vorerst Legacy.
