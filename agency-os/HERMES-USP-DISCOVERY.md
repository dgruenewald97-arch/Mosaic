# Mosaic USP Discovery

## Zweck

Diese Datei beschreibt, welche USPs Mosaic Workbench wirklich haben kann.

Ein USP ist nur stark, wenn er fuer Menschen und Agenturen spueren laesst:

```text
Damit arbeite ich besser, schneller oder sicherer als vorher.
```

## USP-Kriterien

Ein guter Mosaic-USP erfuellt mindestens vier Punkte:

- echter Arbeitsnutzen
- schwer mit einem normalen Chatbot zu kopieren
- erklaerbar in einem Satz
- demo-faehig
- messbar
- wiederverwendbar
- hilfreich fuer Teams, nicht nur Einzelpersonen

## USP 1 - Mosaic Memory Graph

Ein Satz:

```text
Mosaic zeigt nicht nur, was gespeichert ist, sondern wie Wissen, Quellen, Skills, Workflows und Luecken zusammenhaengen.
```

Warum es hilft:

- Teams verlieren weniger Wissen.
- Kampagnen bauen auf Quellen statt Bauchgefuehl.
- Admins sehen, wo das System blind ist.

Demo:

```text
Mosaic Network Report mit Keyfacts.
```

## USP 2 - Claim-Safe Content Velocity

Ein Satz:

```text
Mosaic beschleunigt Marketingtexte, ohne Preise, Angebote oder harte Claims ungeprueft durchzuwinken.
```

Warum es hilft:

- Content wird schneller.
- QA wird leichter.
- Risiko bleibt sichtbar.

Demo:

```text
Haendlermail plus Brand QA.
```

## USP 3 - Affective Decision Layer

Ein Satz:

```text
Mosaic passt Ton, Rueckfragen und Entscheidungskraft an Aufgabe, Risiko und Nutzerfriktion an.
```

Warum es hilft:

- weniger nervige Rueckfragen
- klarere naechste Schritte
- bessere Hilfe, wenn Menschen muede oder unter Druck sind

Demo:

```text
Facebook Monthly: "Ich bin muede, mach mir schnell eine Struktur."
```

## USP 4 - Skill Mining statt Agenten-Zoo

Ein Satz:

```text
Mosaic skaliert ueber gepruefte Skills, nicht ueber immer mehr sichtbare Agenten.
```

Warum es hilft:

- weniger Chaos
- bessere Wiederverwendbarkeit
- klare Versionierung

Demo:

```text
Aus drei guten Haendlermail-Faellen wird ein Skill-Kandidat.
```

## USP 5 - Source-to-Output Trace

Ein Satz:

```text
Mosaic zeigt Admins, welche Quellen, Annahmen und Knowledge Items einen Output getragen haben.
```

Warum es hilft:

- Vertrauen steigt.
- Fehler werden schneller gefunden.
- Wissen kann verbessert werden.

Demo:

```text
Adminansicht nach einer Haendlermail.
```

## USP 6 - Human-Friendly Agent Orchestration

Ein Satz:

```text
Normale Nutzer starten Arbeit, nicht Agentenarchitektur.
```

Warum es hilft:

- weniger Schulungsaufwand
- mehr Akzeptanz
- bessere Workflows

Demo:

```text
Content Assistant direkt, Agency Director nur bei komplexen Aufgaben.
```

## USP 7 - Learning Without Losing Control

Ein Satz:

```text
Mosaic lernt aus Mustern, aber aktiviert Verbesserungen erst nach Review.
```

Warum es hilft:

- System wird besser
- kein unkontrollierter Selbstumbau
- Agenturen behalten Steuerung

Demo:

```text
Network Report schlaegt Skill-Kandidaten vor.
```

## USP 8 - Marketing Workbench Intelligence

Ein Satz:

```text
Mosaic ist kein Textgenerator, sondern eine Workbench fuer Marketingwissen, Produktion und Qualitaet.
```

Warum es hilft:

- verbindet Strategie, Content, QA und Lernen
- passt zu Inhouse-Agenturen
- schafft eine gemeinsame Arbeitslogik

Demo:

```text
Briefing -> Kampagne -> Copy -> QA -> Learning.
```

## Schwaechere USP-Kandidaten

Nicht stark genug:

- "KI schreibt Texte"
- "Agenten automatisieren Marketing"
- "Mehr Kontext"
- "Alles in einem Chat"

Warum:

```text
zu generisch, zu leicht kopierbar, zu wenig agenturspezifisch.
```

## Beste Positionierung

```text
Mosaic Workbench ist eine Marketing Workbench Intelligence:
Sie verbindet Marketingwissen, Promptarbeit, Skills, QA und Lernen auf einer steuerbaren Arbeitsflaeche.
```

## Menschheitsnutzen, ohne groesse Geste

Mosaic hilft Menschen, weil es:

- repetitive Arbeit reduziert
- Wissen weniger leicht verschwinden laesst
- Unsicherheit sichtbar macht
- Teams ruhiger arbeiten laesst
- gute Entscheidungen vorbereitet
- Kreativarbeit weniger chaotisch macht

Merksatz:

```text
Mosaic ersetzt nicht das Team. Mosaic gibt ihm eine bessere Werkbank fuer Wissen und Arbeit.
```
