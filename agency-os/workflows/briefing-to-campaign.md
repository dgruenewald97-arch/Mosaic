# Workflow: Briefing zu Kampagne

## Zweck

Dieser MVP-Workflow verwandelt ein einfaches Briefing in ein Kampagnenkonzept, Copy-Ansatz, Design-Briefing und QA-Hinweise.

## Zielnutzer

- Texter
- Social-Team
- Design
- Handelsmarketing
- Admins

Der Nutzer muss keine Systembegriffe kennen.

## Startformular

Pflicht:

- Marke
- Thema
- Ziel
- Zielgruppe

Optional:

- Produkt
- Zeitraum
- Kanaele
- Angebot / Preis
- vorhandene Unterlagen
- Ton
- No-gos

## Ablauf

```text
1. Input aufnehmen
2. Relevantes Wissen suchen
3. Kampagnenkonzept erstellen
4. Copy-Ansatz erstellen
5. Design-Briefing erstellen
6. QA / Brand Check ausfuehren
7. Ergebnis mit kurzen Risiken ausgeben
8. Optional Learnings oder neue Wissensluecken speichern
```

## Genutzte Memory-Bereiche

- Brands
- Products
- Campaigns
- Knowledge Items
- Learnings
- Sources

## Genutzte Agenten

- Campaign Strategist
- Copy Agent
- Design Brief Agent
- QA / Brand Check

## Antwortformat Standardnutzer

```text
Kampagnenidee
[kurz und klar]

Kernbotschaft
[eine klare Botschaft]

Copy-Ansatz
[Headlines / Textbausteine]

Design-Briefing
[Look, Motive, Formate, Pflichtbestandteile]

Kurz pruefen:
- [maximal 1-2 Risiken]

Genutzt:
- [wichtigste Wissensbereiche]
```

## Antwortformat Admin

Zusaetzlich:

- konkrete Quellen
- Annahmen
- betroffene Knowledge Items
- offene Gaps
- empfohlene Memory-Updates

## Missing-Info-Verhalten

Wenn Zeitraum fehlt:

```text
Ich formuliere ohne konkreten Zeitraum, damit nichts Falsches drinsteht.
```

Wenn Preis fehlt:

```text
Ich nenne keinen Preis, solange keine belastbare Quelle vorliegt.
```

Wenn Produkt fehlt:

```text
Ich halte es markenbezogen. Wenn du ein Modell nennst, kann ich es schaerfer machen.
```

## QA-Pruefung

QA prueft:

- Tonalitaet
- falsche oder unsichere Fakten
- Preise
- Modellnamen
- rechtlich riskante Claims
- fehlende Pflichtinfos
- Abweichung von Brand Voice

Im Standardmodus werden nur die wichtigsten Risiken genannt.

## Abschluss

Nach Ausgabe fragt der Agent nicht offen endlos weiter. Er nennt maximal einen sinnvollen Folgeschritt:

```text
Wenn du willst, mache ich daraus als naechstes eine Haendlermail oder einen Social-Post.
```
