# Airtable MVP Setup

Dieser Ordner enthaelt die praktische Vorbereitung fuer die erste Airtable Base von Mosaic Workbench.

Ziel:

- Base sauber nach Schema anlegen.
- 10 erste Operating-Knowledge-Items als belastbaren Seed vorbereiten.
- 10 echte Pilot-Knowledge-Items aus Quellen vorbereiten.
- Actions spaeter gegen echte Tabellen testen.
- Keine unbelegten Marken-, Produkt- oder Preisclaims einfuehren.

Dateien:

- `airtable-base-build-checklist.md` - Schritt-fuer-Schritt-Aufbau der Base.
- `mvp-knowledge-seed.md` - 10 erste Knowledge Items fuer den MVP.
- `pilot-knowledge-intake-template.md` - Vorlage fuer 10 echte Pilot-Knowledge-Items.

Wichtig:

Diese Dateien ersetzen nicht `../AIRTABLE-MEMORY-SCHEMA.md`. Sie machen das Schema nur praktisch umsetzbar.
