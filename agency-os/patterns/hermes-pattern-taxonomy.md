# Mosaic Pattern Taxonomy

## Zweck

Diese Taxonomie sortiert Agenturarbeit in wiederverwendbare Aufgabenmuster.

## 1. Copy Patterns

Beispiele:

- Haendlermail
- Newsletter-Intro
- Website-Teaser
- Anzeigenvariante
- CTA-Optimierung
- Claim-Alternative

Zielmodus:

```text
Mosaic Prompter / Content Mode
```

## 2. QA Patterns

Beispiele:

- Preis ohne Quelle
- harter Claim
- Tonalitaetsbruch
- Modellnamen-Check
- Angebotslogik pruefen

Zielmodus:

```text
Mosaic Prompter / QA Mode
```

## 3. Campaign Patterns

Beispiele:

- Kampagnenidee aus Briefing
- Zielgruppenlogik
- Botschaftsleiter
- Kanalrollen
- Aktivierungsmechanik

Zielmodus:

```text
Mosaic Prompter / Campaign Mode
```

## 4. Monthly Patterns

Beispiele:

- Facebook Monthly Story
- Performance-Auffaelligkeiten
- Learnings ableiten
- Next-Month Recommendations

Zielmodus:

```text
Mosaic Prompter / Monthly Mode
```

## 5. Knowledge Patterns

Beispiele:

- Produktinfo einordnen
- Brand Voice extrahieren
- Quelle zusammenfassen
- Konflikt erkennen
- Knowledge Item Draft

Zielmodus:

```text
Mosaic Prompter / Knowledge Draft Mode
Mosaic Admin / Memory Mode
```

## 6. Admin Patterns

Beispiele:

- Network Report
- Source-to-Output Trace
- Eval Run
- Skill Candidate Review
- Prompt-vNext Vorbereitung

Zielmodus:

```text
Mosaic Admin
```

## 7. Variant Patterns

Beispiele:

- sachlich
- aktivierend
- premium
- lokal
- kurz
- emotionaler
- haendlernah

Zielmodus:

```text
Mosaic Prompter / Variant Mode
```

## 8. Learning Patterns

Beispiele:

- Kampagnenlearning
- Was hat funktioniert
- Was hat nicht funktioniert
- Empfehlung fuer naechstes Mal
- Evidence Capture

Zielmodus:

```text
Mosaic Prompter / Learning Draft
Mosaic Admin / Memory Mode
```

## Skalierungsregel

```text
Neue Aufgabe -> Pattern pruefen -> Modus waehlen -> Skill-Kandidat nur bei Wiederholung.
```
