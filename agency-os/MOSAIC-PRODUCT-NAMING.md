# Mosaic Product Naming

## Entscheidung

Der neue Produktname ist:

```text
Mosaic Workbench
```

## Warum Mosaic

Mosaic beschreibt, was das System tut:

```text
Verstreutes Wissen wird zu einem nutzbaren Gesamtbild.
```

Es passt zu:

- Memory
- Quellen
- Kampagnen
- Brand Voice
- Skills
- Learnings
- Teamwissen

## Warum Workbench statt Agency

`Agency` beschreibt die Organisation.

`Workbench` beschreibt die Arbeit.

Mosaic ist kein weiterer Agenturbegriff, sondern eine Arbeitsflaeche, auf der Wissen, Prompts, Skills und Outputs zusammenkommen.

## Voller Name

```text
Mosaic Workbench
```

## Kurzname

```text
Mosaic
```

## Beschreibung in einem Satz

```text
Mosaic Workbench verbindet Marketingwissen, KI-Arbeit und wiederverwendbare Skills zu einer klaren Arbeitsflaeche fuer Inhouse-Teams.
```

## Alternativen, verworfen

### Mosaic Agency OS

Wirkt nah an der alten Struktur, aber zu technisch und zu organisationsbezogen.

### Mosaic for Marketing

Verstaendlich, aber generischer.

### Mosaic Intelligence

Klingt gross, aber weniger praktisch.

### Mosaic Studio

Kreativ, aber zu sehr Design-/Content-Studio.

### Mosaic Command

Zu hart und zu sehr Kontrollraum.

## Migrationsregel

Alte Hermes-Dateinamen duerfen vorerst bestehen bleiben.

Neue produktseitige Sprache:

```text
Hermes -> Mosaic
Hermes for Marketing -> Mosaic Workbench
Hermes Prompter -> Mosaic Prompter
Hermes Admin -> Mosaic Admin
Agency OS -> Workbench oder Marketing Workbench
```

## Merksatz

```text
Mosaic ist nicht die Agentur.
Mosaic ist die Werkbank, auf der Agenturwissen nutzbar wird.
```
