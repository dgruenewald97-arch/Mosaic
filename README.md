# Mosaic Workbench

## Aktueller Stand

Dieses Repo enthaelt den privaten internen Pilotstand fuer Mosaic Workbench.

Aktuelle Wahrheit:

```text
agency-os/
```

Mosaic Workbench ist eine KI-gestuetzte Arbeitsflaeche fuer Inhouse-Marketingteams.

Grundhaltung:

```text
Intern arbeiten.
Produktreif denken.
Automatisch verbessern.
Kontrolliert aktivieren.
```

## MVP

Der MVP hat zwei sichtbare Agenten:

```text
Mosaic Prompter
Mosaic Admin
```

Alles andere ist Modus, Skill, Procedure, Eval, Backlog oder Legacy-Referenz.

## Self-Check

Vor dem Anbinden oder nach Aenderungen:

```powershell
powershell -ExecutionPolicy Bypass -File .\agency-os\tools\check-mosaic.ps1
```

## Aktuelle Blocker

Noch praktisch zu erledigen:

1. Privates GitHub-Repo initialisieren oder verbinden.
2. Airtable Base bauen.
3. Seed Knowledge Items eintragen.
4. 10 echte Pilot-Knowledge-Items aus Quellen aufnehmen.
5. Mosaic Prompter und Mosaic Admin in Langdock anlegen.
6. Live-Eval und Teamfeedback sammeln.

## Nicht tun

- keine externe Verwendung ohne Launch-Review
- keine Originaldateien bearbeiten
- keine Preise ohne Quelle
- keine harten Claims ohne Beleg
- keine stillen Commits
- keine neuen sichtbaren Agenten ohne Review
